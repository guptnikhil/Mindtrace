The Innovators Problem, Solution & Core USPs
SIH2026 • MindTrace
⚠️ Understanding The Problem
  • Silent Burnout Gap: 1 in 4 engineering students suffers burnout; only 8% visit campus counselors.
  • Signal Fragmentation: Sleep shifts, skipped labs, and deadline delays happen invisibly.
  • Counseling Stigma: Fear of university record-marking and peer judgment keeps students silent.
  • Late Interventions: Support arrives only after course dropouts or acute crises.
  • Survey Fatigue: 50-question psychological forms alienate stressed students.
💡 Our Solution
  • 60-Second Micro Check-In: 5 key routine sliders (sleep, energy, stress, mood, academic pressure).
  • 14-Day Pattern Index: Moving baseline algorithm spotting early drift weeks ahead.
  • Counterfactual Explorer: Real-time "What-If" simulator showing recovery actions.
  • Calm Companion & Audio: Synthesized ambient Web Audio & empathetic AI chat without clinical labels.
🌟 Unique Solutions (USPs)
  • Zero-Login & Local-First: No college email required; encrypted on student's device.
  • Explainable Drift: Supportive, non-diagnostic transparency behind every score.
  • Live Behavioral Simulator: Students test personal habit shifts in real time.
  • In-Browser Web Audio: 0ms latency soundscapes with zero external dependencies.
  • Anonymous Admin Center: Real-time cohort health analytics with zero PII leaks.

Technical Approach System Architecture & Pipeline
SIH2026 • MindTrace
🔄 End-to-End Methodology Flow
  • Intake: Daily micro-checkin (5 sliders) + optional reflection note.
  • Client Caching: Stale-While-Revalidate (SWR) localStorage hydration for 0ms initial load.
  • Processing: FastAPI + SQLAlchemy ORM deterministic risk & drift engine.
  • Intervention: Dynamic rule-based contextual Nudge generation + 1-tap WhatsApp Counsellor bridge.
🛠️ Tech Stack
Frontend: React 18, TypeScript, Vite, Tailwind CSS, Lucide Icons
Backend & AI: FastAPI, Python 3.11, Pydantic v2, Scikit/Rule Scoring
Database & Audio: SQLite / PostgreSQL, Web Audio API (Synthesizer)
🖥️ Production System Modules
  • Student Portal: Personalized Routine Pattern Index, 14-day history, contextual nudges.
  • Counterfactual Explorer: Interactive sliders simulating late-night minutes, library checkins, and schedule variance.
  • Institutional Dashboard: Differential-privacy cohort view with 6 tabs (Overview, Funnel, Cohorts, Support, Engagement, Reports).
  • Resilient Offline Fallback: Client calculates scoring locally if backend connectivity drops.
API Endpoints: Dual `/api` & `/api/v1` routes with CORS edge proxying Tested & Audited Architecture
